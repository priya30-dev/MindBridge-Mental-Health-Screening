# MindBridge API

Backend for [MindBridge](https://github.com/priya30-dev/MindBridge-Mental-Health-Screening),
a mental-health screening app (English, Hindi, Hinglish).

- Health check: `/health`
- Interactive API docs: `/docs`

MindBridge is a screening tool, not a diagnosis. In India, Tele-MANAS: 14416 (24x7, free). Emergency: 112.
